Live A/V mixing, built for the dance floor

Two-deck video & audio mixing, GPU-composited output to a projector, and real MIDI controller support — free and open source, built for garage dance parties and small live shows.

Install View source

What it does

Two-deck video + audio mixing

Load video clips onto independent decks, crossfade video and audio together, loop playback.

MIDI controller support

Built for the Hercules DJControl Starlight — jog wheels, crossfader, play/pause, volume faders mapped out of the box.

Dedicated projector output

A separate, GPU-composited output window for display 2, driven independently from the control window.

Beat grid & sync

Automatic BPM detection and beat-grid fitting, snap-to-beat seeking, and phase sync between decks.

Audio-reactive visuals

A global GLSL shader layer (plasma, tunnel, particles, feedback, scope) driven by live audio analysis, blended over the video.

Real audio engine

GStreamer/PipeWire backend with per-device routing and a proper headphone cue mix — not a toy player.
